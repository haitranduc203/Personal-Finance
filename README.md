# FinTrack — Antigravity Project Plan

Bộ tài liệu này dùng làm **source of truth** để AI coding agent (ví dụ Antigravity) triển khai project Personal Finance bằng Android Native Kotlin.

## Cách sử dụng

1. Mở toàn bộ thư mục này cùng Android project.
2. Đọc `00_MASTER_PLAN.md` trước.
3. Khi bắt đầu một phase, đọc file phase tương ứng.
4. Thực hiện task theo `05_TASK_BACKLOG.md`.
5. Sau mỗi phase, kiểm tra `06_DEFINITION_OF_DONE.md`.
6. Khi thay đổi kiến trúc/schema/flow, cập nhật tài liệu trước khi code tiếp.
7. Không cho AI tự mở rộng scope nếu task chưa được ghi trong backlog.
